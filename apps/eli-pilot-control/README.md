# Eli Pilot Control

A lightweight, subdomain-ready pilot control panel for Eli.

## What is included

- Health and status panel
- Dry-run command submission form
- Approval toggle
- Latest result display
- Audit/report display
- Pilot state summary

## Notes

- This first version is a static mock UI only.
- All actions are dry-run only.
- The UI clearly marks the experience as Pilot Mode / Dry Run Only.
- It is intended to connect to the Phase 6 pilot runner later through a future subdomain backend.
