# Deployment Checklist

- [ ] Upload the static files from this folder to the target web root.
- [ ] Point the placeholder subdomain DNS record to the deployment host.
- [ ] Configure the reverse proxy to serve this folder over HTTPS.
- [ ] Verify the Pilot Mode / Dry Run Only banner is visible.
- [ ] Confirm the panel does not expose any live execution endpoint.
- [ ] Keep the deployment in dry-run mode only.
