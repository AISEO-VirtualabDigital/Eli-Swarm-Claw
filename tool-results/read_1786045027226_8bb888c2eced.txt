   134→🆕 There's an app now
   135→Agency Agents is a native app for macOS, Linux & Windows that browses the entire roster and installs it into Claude Code, Cursor, Codex, Gemini, Osaurus, and more — with a click. No clone, no scripts, and it auto-updates.
   136→
   137→→ Download the latest release · agencyagents.app
   138→
   139→🚀 What Is This?
   140→Born from a Reddit thread and months of iteration, The Agency is a growing collection of meticulously crafted AI agent personalities. Each agent is:
   141→
   142→🎯 Specialized: Deep expertise in their domain (not generic prompt templates)
   143→🧠 Personality-Driven: Unique voice, communication style, and approach
   144→📋 Deliverable-Focused: Real code, processes, and measurable outcomes
   145→✅ Production-Ready: Battle-tested workflows and success metrics
   146→Think of it as: Assembling your dream team, except they're AI specialists who never sleep, never complain, and always deliver.
   147→
   148→⚡ Quick Start
   149→Option 1: Install the app (Recommended)
   150→The fastest way in — no clone, no terminal. Agency Agents is a native desktop app (macOS · Linux · Windows) that browses the whole roster and installs agents into Claude Code, Cursor, Codex, Gemini CLI, OpenCode, Qwen, and Osaurus for you, then keeps them up to date.
   151→
   152→⬇ Download the latest release — or on a Mac:
   153→
   154→brew install --cask msitarzewski/agency-agents/agency-agents
   155→Prefer the command line? The script-based options below install the same agents.
   156→
   157→Option 2: Use with Claude Code
   158→# Install all agents to your Claude Code directory
   159→./scripts/install.sh --tool claude-code
   160→
   161→# Or manually copy a category if you only want one division
   162→cp engineering/*.md ~/.claude/agents/
   163→
   164→# Then activate any agent in your Claude Code sessions:
   165→# "Hey Claude, activate Frontend Developer mode and help me build a React component"
   166→Option 3: Use as Reference
   167→Each agent file contains:
   168→
   169→Identity & personality traits
   170→Core mission & workflows
   171→Technical deliverables with code examples
   172→Success metrics & communication style
   173→Browse the agents below and copy/adapt the ones you need!
   174→
   175→Option 4: Use with Other Tools (GitHub Copilot, Antigravity, Gemini CLI, OpenCode, OpenClaw, Cursor, Aider, Windsurf, Kimi Code, Codex, Osaurus, Hermes, Mistral Vibe)
   176→# Step 1 -- generate integration files for all supported tools
   177→./scripts/convert.sh
   178→
   179→# Step 2 -- install interactively (auto-detects what you have installed)
   180→./scripts/install.sh
   181→
   182→# Or target a specific tool directly
   183→./scripts/install.sh --tool antigravity
   184→./scripts/install.sh --tool gemini-cli
   185→./scripts/install.sh --tool opencode
   186→./scripts/install.sh --tool copilot
   187→./scripts/install.sh --tool openclaw
   188→./scripts/install.sh --tool cursor
   189→./scripts/install.sh --tool aider
   190→./scripts/install.sh --tool windsurf
   191→./scripts/install.sh --tool kimi
   192→./scripts/install.sh --tool codex
   193→./scripts/install.sh --tool osaurus
   194→./scripts/install.sh --tool hermes
   195→./scripts/install.sh --tool vibe
   196→Install only the teams you need (not everyone wants every division):
   197→
   198→./scripts/install.sh                                    # interactive wizard: pick tools + teams
   199→./scripts/install.sh --tool claude-code --division engineering,security
   200→./scripts/install.sh --tool cursor --agent frontend-developer,ui-designer
   201→./scripts/install.sh --list teams                       # see every team + agent count
   202→./scripts/install.sh --tool opencode --division engineering --dry-run
   203→OpenCode note: OpenCode's runtime currently registers only ~119 agents and silently drops the rest (upstream bug). Installing a subset with --division keeps you under that limit. The installer warns you when a selection would exceed it.

   747→Faster runs (parallel) — On multi-core machines, use --parallel so each tool is processed in parallel. Output order across tools is non-deterministic. Works with both interactive and non-interactive install: e.g. ./scripts/install.sh --interactive --parallel (pick tools, then install in parallel) or ./scripts/install.sh --no-interactive --parallel. Job count defaults to nproc (Linux), sysctl -n hw.ncpu (macOS), or 4; override with --jobs N.
   748→
   749→./scripts/convert.sh --parallel                    # convert all tools in parallel
   750→./scripts/convert.sh --parallel --jobs 8           # cap parallel jobs
   751→./scripts/install.sh --no-interactive --parallel   # install all detected tools in parallel
   752→./scripts/install.sh --interactive --parallel      # pick tools, then install in parallel
   753→./scripts/install.sh --no-interactive --parallel --jobs 4
