# Eli-OS Phase 2 Roadmap

Phase 2 starts after Phase 1 is merged.

## Goal

Connect the secure audited boundary layer to controlled runtime handoff contracts.

## Sequence

1. Boundary runtime adapter
2. Runtime dispatch contract
3. Human approval gate
4. Queue interface
5. Worker contract
6. Persistence interfaces

## Rule

Accepted boundary processing is not execution.

Execution must stay separate, auditable, and approval-aware.
