# Pilot Subdomain Static Deployment

## Overview

This document provides a placeholder-only deployment scaffold for the Eli pilot control panel under apps/eli-pilot-control.

## Files included

- apps/eli-pilot-control/.env.example
- apps/eli-pilot-control/DEPLOYMENT_CHECKLIST.md
- apps/eli-pilot-control/nginx-subdomain.conf
- apps/eli-pilot-control/static-server.py

## Deployment notes

- Keep the deployment dry-run only.
- Do not expose any live execution endpoint.
- Use placeholder subdomain values only.
- Do not add production secrets.
