Options</h3>\n<p>For more fine-tuned control over how your API calls are made, we provide you with the ability to specify additional options that can be applied directly to the <a href=\"https://github.com/JustinBeckwith/gaxios\">'gaxios'</a> object used in this library to make network calls to the API.</p>\n<p>You may specify additional options either in the global <code>google</code> object or on a service client basis.
