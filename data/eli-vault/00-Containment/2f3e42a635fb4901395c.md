   ```
   npm i zod playwright llm-scraper
   ```
2. Initialize your LLM:

   **OpenAI**

   ```
   npm i @ai-sdk/openai
   ```

   ```js
   import { openai } from '@ai-sdk/openai'
const llm = openai('gpt-4o')
   ```

