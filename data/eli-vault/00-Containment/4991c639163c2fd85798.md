## LLM Backend Integration
### Grok API via chenyme/grok2api
Deploy the grok2api Docker container as an OpenAI-compatible proxy. Configure it with an xAI API key. Point the agent orchestration layer's LLM configuration to this proxy endpoint using the standard OpenAI SDK.
