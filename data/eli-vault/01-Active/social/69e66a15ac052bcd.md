# Video Tags
## How to Use It

```python
import YoutubeTags
from YoutubeTags import videotags
link = "Add Your Youtube Link Here" # Use https / http Links
variable_name = videotags(link)
print(variable_name)
```
> **_NOTE:_** ONLY SUPPORTS HTTP(S) , use HTTP(S) links to get the results
