# Agent Eli v1 — Human-Led AI SEO Operating System

This package is a new consolidated Agent Eli prototype and backend scaffold.

It includes:

- Premium public portfolio/viewer UI
- Private Baserow-inspired operator workspace
- Orange Orbit legacy capability mapping
- Open integration registry
- Open SEO skill registry
- White-Label Parasite SEO Strategist
- Authority Link Acquisition Strategist
- Site audit, content decay, cannibalization, indexation, local SEO, AI citation and conversion-path modules
- Approval-gated execution states
- FastAPI backend scaffold
- PostgreSQL, Redis and n8n-ready infrastructure
- Obsidian/Google Drive knowledge-layer architecture
- Security and human-in-the-loop rules

## Run the visual prototype

Open:

`frontend/public/index.html`

No build step is required for the prototype.

## Run the backend scaffold

```bash
cd backend
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
uvicorn app.main:app --reload
```
