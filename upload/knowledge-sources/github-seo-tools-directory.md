## OpenSEO Keyword Clustering

OpenSEO is an open-source alternative to Semrush and Ahrefs. The Keyword Clustering Agent Skill turns a messy keyword list into a page plan. Your agent sorts keywords, compares intent, and decides which terms belong on the same page.

**Source**: https://openseo.so/docs/skills/keyword-clustering

### What it does

- Group keywords by intent, SERP similarity, and page type
- Separate terms that look similar but need different pages
- Map clusters to existing URLs when they fit
- Recommend new pages when no current page matches the search intent
- Flag weak, off-strategy, or do-not-target keywords
- Suggest saved keyword tags only after user confirmation

### When to use it

- You already have keywords but do not yet have a content plan
- A keyword export is too large to sort by hand
- Multiple pages might compete for the same intent
- You need to turn research into page briefs

### What you get back

Clusters, primary keywords, secondary keywords, search intent, page targets, priorities, and notes about cannibalization or consolidation.

### Related OpenSEO Skills

- **Keyword Research** — when you need more candidate terms
- **Competitor Analysis** — when competitor pages should inform the map
- **SEO Coach** — if unsure whether clustering is the next step
- **SEO Audit** — comprehensive site auditing
