## Overview

Ahrefs SEO Toolbar is a free browser extension that provides detailed SEO insights without leaving your browser. Trusted by 360,000+ SEO professionals worldwide.

## Key Features

### Global SEO Research (No VPN needed)
Switch regions, Google domains, and languages directly in the extension. Get new keyword ideas and search data from any location without needing a VPN connection.

### On-Page SEO Data in 1 Click
Check titles, meta descriptions, headers, and technical SEO factors like canonical tags and indexation directives in a single click. Quickly audit any page's SEO fundamentals.

### Link Analysis Made Easy
- Highlight links on any page
- Trace redirect chains
- Filter outgoing links (external vs internal)
- Spot broken links
- Export all link data to CSV for further analysis

### Detailed SEO Research Tools
- Save URLs from open tabs or SERP results
- Switch user agents to see pages as Googlebot sees them
- Read HTTP headers for debugging
- Get performance data from Page Speed Insights

### Ahrefs Metrics (Paid)
For Ahrefs subscribers, the toolbar unlocks domain and page-level metrics directly on every site or search result:
- Keyword rankings and counts
- Traffic estimates
- Referring domains count
- Domain Rating (DR)
- URL Rating (UR)

## Pricing
- Core tools: **Free** (on-page audit, link highlight, redirect trace, user agent switch)
- Ahrefs metrics: Requires **Ahrefs subscription** (starting plans available)
